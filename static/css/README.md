# Employee Management Portal

## Project Description

The Employee Management Portal is a web-based application used to manage employee information easily.

It allows users to add, view, search, filter, edit, and delete employee records.

## Technologies Used

- Python
- Flask
- Jinja2
- Flask-SQLAlchemy
- SQLite
- HTML
- CSS

## Features

- Add Employee
- View Employee List
- Edit Employee Information
- Delete Employee
- Search Employees
- Filter Employees by Employment Status
- Dashboard with Employee Counts
- Active, On Leave, and Resigned Status
- SQLite Database

## Employee Details

The portal stores:

- Employee ID
- Full Name
- Email Address
- Phone Number
- Department
- Designation
- Joining Date
- Salary
- Location
- Employment Status
